What AKA Recht is

A local folder with a user interface in the browser. Every legal matter is a case with a fixed identifier (R-0001, R-0002 …), whether it concerns employment, a fine, rent, a contract or an authority. Everything stays on this computer.

How a case starts

  • “New case”: name, area, your own role, goal.
  • The file gets the fixed folders 01 Eingang to 08 Archiv, a file akte.json for all filing data and a journal.
  • Add incoming mail under “Documents” or put it into 01 Eingang in {dm}. Every file gets an identifier (D0001 …) and a checksum.

Organising without changing originals

  • “Organise” only changes title, date, type, state, topics, exhibit, people and references.
  • “File” moves the file into a section of the case. Identifier and content stay the same.
  • If you move a file in {dm}, the app finds it again by its checksum.

Deadlines

  • A deadline needs a trigger (receipt), a legal basis, a calculation and a source. Only then may it be “confirmed”.
  • The calculator shows every calculation under §§ 187, 188, 193 BGB (German Civil Code). It does not decide which deadline applies.

Backup

  • “Create verified backup” writes a ZIP file outside the project, reads it back and compares every file. A copy goes to the second target if one is set up.
  • “Test the restore” unpacks the last backup into a temporary folder, checks the case files and checksums and clears the folder again. For a real restore into a new folder use python3 "06 Werkzeuge/dienst/server.py" --restore <ZIP> <new folder>, never over the folder you are working in.
  • Three levels that are not the same thing: storage on this computer; synchronisation by the operating system if a target lies in iCloud Drive or another cloud folder (the ZIP file is unencrypted); processing by the AI you connect, at its provider.
  • Before the filing data is saved, the previous version is stored outside the project.

Working with an AI

  • The app contains no AI. It is a case folder that any AI can use: Claude Code, Codex and others read the instructions in the folder (CLAUDE.md, AGENTS.md) and work with the same tools as this interface.
  • An AI may only write through the tools; originals stay locked. Writing tools run only after you have confirmed the call.

Connecting an AI (MCP)

MCP is the interface through which an AI calls the tools of the folder. The server is the file “06 Werkzeuge/dienst/mcp_server.py”; it only needs Python 3.

  • Claude Code: start a session in the project folder. The file “.mcp.json” is included; on the first start Claude Code asks whether it may load the server from the project. Check with “/mcp”. Skills such as “/fristencheck R-0001” are under “.claude/skills/”.
  • Codex: once in the terminal enter “codex mcp add aka-recht -- python3 "full path to mcp_server.py"” (on Windows “python” instead of “python3”), then start Codex in the project folder and check with “/mcp”. Codex loads the included “.codex/config.toml” only if exactly this project folder is entered as trusted in “~/.codex/config.toml”; then “codex mcp add” is not needed. Skills are under “.agents/skills/” and are called with “$fristencheck”.
  • Claude Desktop: menu Claude, Settings, Developer, “Edit configuration”. In the file claude_desktop_config.json add an entry “aka-recht” under “mcpServers” with command “python3” (on Windows “python”) and args [full path to mcp_server.py], paths absolute. Then quit Claude Desktop completely and start it again.
  • Without MCP: any AI that may run commands uses “python3 06 Werkzeuge/dienst/cli.py liste”.

Limits

The app is not a lawyer. Checksums prove identity, not authenticity. A date in the calendar is not a confirmed statutory deadline. The app does not send, file or delete anything.
